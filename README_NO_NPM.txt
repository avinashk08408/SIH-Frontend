SIH26183 PERSON 4 FRONTEND — QUICK START

IMPORTANT:
This is a React/Vite project. React itself needs Node.js and npm to install/run the source project.

WINDOWS:
1. Double-click RUN_WINDOWS.bat.
2. If Node.js/npm is missing, the script tries to install Node.js LTS using winget.
3. After installation, run RUN_WINDOWS.bat again.
4. The script runs npm install and then npm run dev.

MAC / LINUX:
Run:
  ./RUN_MAC_LINUX.sh

If Node.js is missing, install Node.js LTS from:
  https://nodejs.org/
Then run the script again.

DO NOT replace Person 1/2 files with this folder.
Keep this frontend isolated in its own frontend/ directory.
